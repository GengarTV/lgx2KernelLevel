## 1. Executive Summary

This document specifies the four-part logical patch series constructed to introduce the `gc550` driver into the Linux kernel under `drivers/media/usb/gc550/`.

The series isolates driver functionality into discrete, incremental, bisectable patches:
1. **Patch 1/4:** USB driver skeleton, lifecycle, and registration.
2. **Patch 2/4:** USB command bridge and peripheral initialization (*Blocked pending provenance*).
3. **Patch 3/4:** V4L2 / Videobuf2 streaming capture pipeline and BT.1120 stream demultiplexer.
4. **Patch 4/4:** ALSA PCM audio capture subdriver for multiplexed LPCM audio.

In accordance with Phase 3 instructions, the custom 20 MiB diagnostic ring buffer (`gc550-diag.[ch]`) is completely excluded from the upstream patch files while being preserved untouched in the development repository.

  - Dedicated 32 KiB pair-buffer staging area handling 16 KiB FX3 DMA
    buffer swaps dynamically.
  - Runt frame detection and abort handling during resolution changes.
  - Multi-resolution support: 1080p60, 720p60, 576p50, and 480p60 YUYV.

  Signed-off-by: Øystein Lie <oeystein@gengartv.com>

## 4. Upstream Subsystem Review Preparation

| Subsystem Area | Upstream Review Focus | GC550 Implementation Defense |
|---|---|---|
| **V4L2 / VB2** | Buffer queue lifecycle & locking | Uses standard `vb2_vmalloc_memops` with `dev->v4l2_lock` protecting ioctls and queue state. Monotonic timestamping via `V4L2_BUF_FLAG_TIMESTAMP_MONOTONIC`. |
| **USB Core** | Multi-subsystem refcounting | Top-level `gc550_dev` is reference-counted via `kref`. File releases from V4L2 (`video_device`) and ALSA (`snd_card`) release their references independently; disconnect drops driver binding reference. Device memory cannot be freed while userspace holds open descriptors. |
| **ALSA** | Period elapsed context | `snd_pcm_period_elapsed()` is invoked outside spinlocks. Teardown uses `wait_event()` on `alsa_inflight` counter to prevent race conditions during `hw_free`, `close`, or `disconnect`. |
| **Memory** | High-order allocations | 512 KiB URBs use `kmalloc(..., GFP_KERNEL)` (Order 7). Can be transitioned to `usb_alloc_coherent()` if requested by USB maintainers. |
